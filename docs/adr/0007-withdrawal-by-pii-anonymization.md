# ADR-0007: 회원 탈퇴는 PII 익명화로 처리

- 상태: 채택됨
- 결정일: 2026-08-18
- 소급 작성: 2026-11-24

## 맥락

처음 설계는 탈퇴를 소프트 삭제(`status=WITHDRAWN`)로 정했다. 주간·월간 분석과 리포트가 과거 데이터를 참조하므로 완전 삭제하지 않고
비활성화만 하려는 판단이었다. 그런데 개인정보 보호법상 탈퇴한 사용자의 개인정보는 지체 없이 파기해야 한다(제21조). 소프트 삭제만으로는
이메일 같은 개인정보가 그대로 남는다.

## 결정

탈퇴하면 계정 행은 남기되 개인정보(PII)를 되돌릴 수 없는 값(`withdrawn-{id}`)으로 바꿔 파기한다. 같은 소셜 계정으로 다시 로그인하면 새 계정이 만들어진다.
운동 기록은 민감정보가 아니라고 판단했다. 이는 법률 자문이 아니라 실무 관행에 따른 판단이다.

## 검토한 대안

- 상태만 바꾸는 소프트 삭제: 분석 참조는 유지되지만 개인정보가 남아 파기 의무와 맞지 않는다.
- 행을 완전히 삭제: 개인정보는 사라지지만 과거 분석과 리포트가 참조하는 데이터가 깨진다(초기 설계가 기각한 이유).

## 결과

- 얻는 것: 분석 데이터는 유지하면서 개인정보는 파기된다. 처리방침과도 일치한다.
- 감수하는 것: 탈퇴 후 복구할 수 없고, 재가입하면 이전 기록이 이어지지 않는다. 심박수나 수면 같은 생체 지표를 추가하면 민감정보 여부를 다시 검토해야 한다.
