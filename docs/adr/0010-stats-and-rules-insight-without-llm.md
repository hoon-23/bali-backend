# ADR-0010: 인사이트는 통계와 규칙 기반으로 만들고 LLM을 쓰지 않음

- 상태: 채택됨
- 결정일: 2026-08-07 (자연어 질의 API 폐기: 2026-09-10)
- 소급 작성: 2026-11-24

## 맥락

초기 설계는 주간 분석 결과를 Claude API로 해석해 인사이트를 만드는 구조였다. 이후 통계만으로 충분하다고 판단했다.
집계 지표(총 운동시간, 종목·근육군별 볼륨, 완료율, 빈도와 강도)의 전 기간 대비 증감률에서 정해진 규칙으로 문장을 만들 수 있다.

## 결정

인사이트 문장은 통계 계산과 규칙 평가로 만들고 LLM을 쓰지 않는다. 자연어 질의 API도 하지 않기로 하고 2026-09-10에 범위에서 뺐다.

## 검토한 대안

- Claude API로 분석 결과를 해석하는 인사이트(초기 설계): 통계만으로 충분하다는 판단으로 도입하지 않았다.
- 자연어 질의 API: 같은 이유로 범위에서 뺐다.

## 결과

- 얻는 것: 외부 API 의존과 호출 비용이 없고, 같은 입력은 항상 같은 문장이 나온다. 배치가 단순하다.
- 감수하는 것: 문장이 정해진 규칙에서 나오므로 표현이 정형화된다.
